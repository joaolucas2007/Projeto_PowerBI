# Projeto Sample Superstore -- Power BI

Projeto pessoal de análise de dados desenvolvido com **Power BI**, utilizando o dataset **Sample Superstore**.

O objetivo deste projeto é praticar e demonstrar conhecimentos em **Power Query, modelagem de dados, DAX e desenvolvimento de dashboards**, transformando dados brutos em informações úteis para análise de vendas e desempenho.


## Tecnologias

* Power BI
* Power Query
* DAX
* Git / GitHub

##  Objetivos

* Realizar o tratamento e a transformação dos dados;
* Construir um modelo de dados adequado para análise;
* Práticar de estrutura Fato Dimensão;
* Desenvolver medidas utilizando DAX;
* Criar dashboards interativos;
* Explorar indicadores de vendas, lucro, clientes, produtos e devoluções;
* Praticar a construção de um projeto completo de análise de dados para portfólio.


##  Fonte dos dados

Dataset **Sample Superstore**, utilizado para fins de estudo e desenvolvimento do projeto.
Fonte: [Tableau Public — Sample Data](https://public.tableau.com/app/learn/sample-data)

## Desenvolvimento

O projeto foi desenvolvido seguindo as principais etapas de um processo de análise de dados:

### 1. Tratamento dos dados

Inicialmente, os dados brutos foram importados para o **Power BI** e tratados utilizando o **Power Query**.

Foram realizadas etapas de limpeza e transformação dos dados, preparando as informações para a etapa de modelagem e análise.

### 2. Modelagem dos dados

Após o tratamento, foi construída uma estrutura de dados utilizando o conceito de **modelo dimensional (Fato e Dimensões)**.

A modelagem foi organizada buscando facilitar os relacionamentos entre as tabelas e permitir análises de vendas, clientes, produtos, regiões e períodos.

![Modelo Star Schema](./Imagens/Modelo_Fato-Dim.png)

### 3. Criação das medidas

Com o modelo estruturado, foram desenvolvidas medidas utilizando **DAX** para obtenção dos principais indicadores do projeto.

Entre os indicadores analisados estão:

- Total de vendas;
- Total de lucro;
- Margem de lucro;
- Quantidade de pedidos;
- Quantidade de clientes;
- Análise de vendas por região;
- Análise de vendas por cliente;
- Análise de vendas por produto.

### 4. Desenvolvimento dos dashboards

Após a preparação dos dados e criação das medidas, foram desenvolvidos dashboards interativos no **Power BI**.

As análises foram organizadas em diferentes perspectivas:

- **Vendas por Local:** análise por região, estado e cidade;
- **Vendas por Clientes:** análise de clientes, segmentos, vendas e lucratividade;
- **Vendas por Produtos:** análise de categorias, subcategorias, produtos e rentabilidade.

Foram utilizados filtros e diferentes tipos de visualizações para permitir a exploração dos dados de forma interativa.

### 5. Análise dos resultados

Por fim, o dashboard foi utilizado para explorar indicadores de **vendas, lucro, margem, clientes, produtos e regiões**, buscando identificar padrões, diferenças de desempenho e produtos ou clientes com resultados positivos e negativos.

O projeto foi desenvolvido com foco em praticar o fluxo completo de um projeto de análise de dados, desde o tratamento dos dados até a construção e apresentação das informações.
