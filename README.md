# Projeto Sample Superstore -- Power BI

Projeto pessoal de análise de dados desenvolvido com **Power BI**, utilizando o dataset **Sample Superstore**.

O objetivo deste projeto é praticar e demonstrar conhecimentos em **Power Query, modelagem de dados, DAX e desenvolvimento de dashboards**, transformando dados brutos em informações úteis para análise de vendas e desempenho.


## Tecnologias

* Power BI
* Power Query
* DAX
* Git / GitHub

##  Objetivos

* Realizar o tratamento e a transformação dos dados;
* Construir um modelo de dados adequado para análise;
* Práticar de estrutura Fato Dimensão;
* Desenvolver medidas utilizando DAX;
* Criar dashboards interativos;
* Explorar indicadores de vendas, lucro, clientes, produtos e devoluções;
* Praticar a construção de um projeto completo de análise de dados para portfólio.


##  Fonte dos dados

Dataset **Sample Superstore**, utilizado para fins de estudo e desenvolvimento do projeto.
Fonte: [Tableau Public — Sample Data](https://public.tableau.com/app/learn/sample-data)
